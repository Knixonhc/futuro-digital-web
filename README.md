# Futuro Digital Ecuador

Sitio web corporativo de Futuro Digital Ecuador.

## Enfoque
Marca/estudio digital ecuatoriano orientado a pequeñas empresas, negocios y proyectos.

## Servicios
- Desarrollo web
- Software y desarrollos a medida
- Hosting y dominios
- Correo corporativo
- Soporte y continuidad
- Social Media

## Historia
Futuro Digital Ecuador inició en 2019 como una iniciativa independiente orientada a potenciar pequeñas empresas, negocios y proyectos mediante soluciones digitales. Tras una pausa durante la pandemia, la marca retoma su evolución como estudio digital, integrando desarrollo web, software a medida, hosting, dominios, correo corporativo y soporte.

## Tecnología del sitio
HTML, CSS y JavaScript sin dependencias de servidor, compatible con GitHub Pages y despliegue directo en cPanel/public_html.
